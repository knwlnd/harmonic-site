How it works

A harmonic instrument between you and your MIDI instruments.

Harmonic is designed as an instrument, not a suggestion engine. Its behaviour is intentional and repeatable, so it can be learned and performed.

The performance surface

The computer keyboard is the primary surface because it is immediate, portable and already available. Harmonic uses that surface to keep setup overhead low and keep attention on musical decisions.

Tonal context

The musician selects a key and tonal system. Harmonic then interprets performance input consistently within that context, so musical behaviour can be explored without requiring advanced theory knowledge first.

Coordinated outputs

Harmonic currently focuses on Chords, Bass and Solo. Each output can be routed to a different virtual instrument or MIDI destination, allowing several roles to respond together from one performance.

Performance modifiers

Modifiers shape musical behaviour while preserving the keyboard-first model. They allow variation without forcing the musician out of the performance.

Visual feedback

The interface communicates the current tonal context, selected controls, active musical behaviour, output state and performance changes continuously.

Deterministic behaviour

Harmonic does not create a finished composition on behalf of the musician. It provides an instrument through which the musician can perform one.
