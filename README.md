# harmonic-site

Public GitHub Pages website for Harmonic, a keyboard-first harmonic performance instrument for macOS.

The macOS application source lives in the private `harmonic` repository. This public website must not include private application source, credentials, signing materials, distribution tokens, or links that require private repository access.

## Local Preview

Open `index.html` in a browser, or run any static file server from this directory.

## Pages

- `index.html`
- `how-it-works.html`
- `getting-started.html`
- `roadmap.html`
- `engineering.html`
- `feedback.html`
- `privacy.html`
- `404.html`

## Deployment

GitHub Pages deployment is configured in `.github/workflows/pages.yml`.
